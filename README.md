# Void Pointer as Function Context

## Author
M.Likitha

## Description
This program demonstrates using a void pointer together
with a function pointer.

The processData() function receives both a data address
and a function that determines how the data should be
processed.

This allows the same processData() function to work with
different operations and data types.

## Concepts Used
- Void pointer
- Function pointer
- Callback function
- Function parameters
- Type casting
- Dereferencing

## How to Run

gcc void_pointer_function_context.c -o void_pointer_function_context

./void_pointer_function_context
